About CiteVerify

CiteVerify is a Scientific Claim and Citation Verification System built for INNOVEDGE HACKATHON 2026. It prevents misattributed citations, unsupported numerical claims, and hallucinated references in academic manuscripts.

Backend Architecture

Powered by Python Flask (final.py), PyMuPDF & python-docx document extraction, OpenAlex / Crossref / arXiv literature retrieval, BM25 passage ranking, and Anthropic Claude evidence verification with verbatim quote enforcement.

Backend API Endpoints
  • GET /api/v1/health — Server & LLM availability status
  • POST /api/v1/analyze — Document upload & verification pipeline
  • GET / POST /api/v1/reviews — Human reviewer audit log
  • GET /api/v1/export/<json|csv> — Structured report downloads
